# Chào mừng đến với blog của tôi!

Đây là bài viết đầu tiên trên blog cá nhân của tôi. Blog này được xây dựng theo pipeline:

**Obsidian → Hugo → GitHub Pages**

## Pipeline hoạt động như thế nào?

1. **Viết bài** trong Obsidian (markdown đơn giản)
2. **Chạy script** `./update-blog.sh` để đồng bộ
3. **Blog tự động** được cập nhật trên GitHub Pages

## Tính năng

- Frictionless - Viết bài ngay trong Obsidian
- Tự động đồng bộ hình ảnh từ Obsidian attachments
- Terminal theme (retro style)
- Tự động deploy lên GitHub Pages
